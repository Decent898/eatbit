# AstrBot EatBit 插件

## 使用

1. 群内 `@机器人 登录`，打开机器人私聊发送的一次性链接。
2. 群内 `@机器人 记录吃饭`，随后分开发送一张图片和若干条说明。
3. 发送 `完成`，检查匹配结果并补充 1～5 分评分。
4. 发送 `确认` 后写入 EatBit；发送 `取消` 放弃草稿。

插件只会自动匹配现有店铺/菜品，不会根据聊天内容擅自创建店铺或修改菜品价格。

匹配不到现有店铺时，可以继续发送：

```text
新店：店铺名称
区域：东食堂
完成
```

预览会明确显示“将新建”，确认后才会同时创建店铺和用餐记录。菜品和公共价格仍不会自动创建或修改。
