# AstrBot EatBit 插件

## 使用

1. 发送 `@机器人 介绍 EatBit` 或 `@机器人 EatBit 帮助` 查看当前功能和操作说明。
2. 群内 `@机器人 记录吃饭`；未绑定时会先给出绑定链接，使用与网页/小程序一致的 EatBit 账号。
3. 绑定后重新发送 `@机器人 记录吃饭`，随后分开发送一张图片和若干条说明。
4. 发送 `完成`，检查匹配结果并补充 1～5 分评分。
5. 发送 `确认` 后写入 EatBit；发送 `取消` 放弃草稿。

第一次发送 `完成` 后进入 AI 表单编辑状态。缺少内容或存在歧义时，机器人会列出需要补充的项目；之后直接回复“菜品改成糖霜番茄”“店铺不是这个，是自带食物”“评分 4.5”等自然语言，机器人会自动重新整理并给出可确认的新版预览，不需要再次发送 `完成`。

评分也可以直接写在第一次结束消息里，例如 `完成，评分 4.5`。

插件会先调用 AstrBot 当前模型把连续聊天整理成区域、店铺、菜品、价格、餐次、评价和评分，再和 EatBit 目录校验。模型匹配不到时会明确标注准备新建，只有用户确认后才写入。

匹配不到现有店铺时，可以继续发送：

```text
新店：店铺名称
区域：东食堂
完成
```

预览会明确显示“将新建”，确认后才会同时创建店铺、菜品和用餐记录。
