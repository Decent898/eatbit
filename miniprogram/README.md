# 吃在北理微信小程序

这是 `吃在北理` 的原生微信小程序版本，目录为 `miniprogram/`。它复用现有 Cloudflare Pages Functions + D1 数据，不单独维护另一套数据库。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本目录：`miniprogram/`。
4. AppID 可以先使用测试号或你自己的正式小程序 AppID。

## 需要配置的合法域名

小程序后台需要把以下域名加入 request 合法域名：

```text
https://eat.bitdate.date
```

如果只是本地预览，可在微信开发者工具里临时勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。

## 已复刻功能

- 首页：复刻 Web 手机端的“骰一下 / 区域 / 搜索 / 榜单 / 今天”五栏目。
- 区域页：查看区域下的店面列表，登录后可添加店面和上传店铺图片。
- 店铺详情：查看店铺、菜品表、AI 总结、评分留言；可添加菜品、写评价、上传图片、标记关门/恢复营业、标记菜品下架/恢复。
- 搜索和榜单：统一在首页栏目里展示，自动过滤已关门店铺和已下架菜品。
- 骰一下：按默认校区或选定区域随机推荐菜品；候选区域默认空白，自动过滤不可用内容。
- 今天吃了什么：记录个人吃饭，可新增不存在的店铺/菜品，可选择是否同步成公开评价。
- 个人中心：昵称/邮箱登录，设置默认校区，查看最近一周吃饭统计和二级记录列表。
- 问题反馈：提交工单到现有反馈系统。
- 区域管理：新增或修改食堂区/区域。

## 和 Web 版的差异

- 小程序版使用现有“昵称/邮箱登录”，不接入微信授权登录。
- 小程序端图片会通过 `wx.chooseMedia` / `wx.compressImage` 尽量压缩到 100KB 内，再调用现有接口保存。
- 复杂管理能力以移动端常用操作为主，完整后台仍建议使用 Web 版。
